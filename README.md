Neste projeto, realizei uma análise exploratória e tratamento de dados de um dataset de e-commerce disponibilizado no Kaggle:

🔗 https://www.kaggle.com/datasets/datascikhan/e-commerce-orders-and-transactions-2026-dataset


O dataset possui 200.000 registros envolvendo pedidos, clientes, produtos, pagamentos, descontos, fretes, entregas, devoluções e indicadores financeiros.
